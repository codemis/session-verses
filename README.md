# Claude Session Verses

A Claude Code mod that shows one random Bible verse (BSB), with its reference,
above the prompt for each session.

## Install

```
/plugin marketplace add codemis/session-verses
/plugin install session-verses@session-verses-mods
```

See [session-verses/README.md](session-verses/README.md) for details and
[LICENSE](session-verses/LICENSE) (MIT, code only).
